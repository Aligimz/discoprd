# نظام إدارة طاقم Discord

## المتطلبات
Node.js 18+ و PostgreSQL 14+

## التثبيت
1. `cp .env.example .env` ثم عبّئ القيم.
2. أنشئ قاعدة البيانات ثم: `npm install && npm run db:init`
3. `npm start` ثم افتح BASE_URL.

## إنشاء حساب المالك الأول
ضع Discord ID الخاص بك في `OWNER_DISCORD_ID`، ثم سجّل الدخول عبر Discord. أول دخول لهذا المعرّف ينشئ حساب المالك تلقائياً (لا يُسمح بأكثر من مالك واحد). أي شخص آخر يجب أن تضيفه أنت إلى جدول web_users.

## ربط Discord
1. في Developer Portal أنشئ Application وأضف Redirect: `BASE_URL/auth/callback`.
2. في تبويب Bot فعّل **SERVER MEMBERS INTENT** وانسخ التوكن إلى `DISCORD_BOT_TOKEN`.
3. ادعُ البوت للسيرفر (صلاحية قراءة فقط تكفي) وضع `GUILD_ID`.
4. من صفحة «المزامنة» اضغط «مزامنة الآن».
5. من «الرتب» اربط كل رتبة بـ Discord Role ID، وعلّم الرتب الإدارية، ثم زامن مجدداً لإنشاء الملفات.

## وضع التجربة
`DEMO=1` يفتح دخولاً تجريبياً بدون Discord (للتجربة المحلية فقط، لا تستخدمه على الإنترنت). لا بيانات حقيقية تظهر قبل نجاح المزامنة.

## الحالة
نسخة أساسية لم تُختبر على بيئة حقيقية. غير مكتمل: الشكاوى والمهام والتوظيف (جداولها موجودة بلا واجهات)، المخطط التنظيمي التفاعلي، الرسوم البيانية، الفلاتر المحفوظة، اختبارات آلية.
